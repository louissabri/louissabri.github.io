Grasshopper Web App

A node.js web application for interacting with Grasshopper definitions through a browser interface.

Project Overview

This project bridges the gap between parametric design tools and web applications by creating a platform that allows users to interact with Grasshopper definitions through a browser interface. The goal was to make parametric design more accessible to non-technical users and enable remote collaboration on design projects.

Technologies Used

  • Node.js and Express (Backend)
  • React.js and Three.js (Frontend)
  • Rhino Compute Server (Grasshopper Processing)
  • WebSockets for real-time updates
  • MongoDB for project data storage

Development Process

The development began with setting up a Rhino Compute server that could process Grasshopper definitions based on input parameters. I then created a Node.js API that would communicate with this compute server and handle user requests.

On the frontend, I built a React application with an intuitive interface that allows users to adjust parameters using sliders, input fields, and other interactive elements. The application visualizes the resulting 3D models in real-time using Three.js, providing instant feedback as parameters are changed.

Key Features

Real-time Visualization: Changes to parameters are instantly rendered in 3D, allowing for quick design iterations.

Collaborative Editing: Multiple users can work on the same definition simultaneously, with changes synchronized across all connected clients.

Project Management: Users can save, share, and manage multiple design projects through the platform.

Export Options: Designs can be exported in various formats (OBJ, STL, STEP) for further processing or fabrication.

Challenges & Solutions

One of the main challenges was optimizing the compute server to handle multiple requests efficiently. I implemented a queuing system and caching mechanism to improve performance and reduce redundant calculations.

Another challenge was creating an intuitive user interface that could represent the complex relationships in Grasshopper definitions. Through multiple iterations and user testing, I developed a component-based interface that visually represents dependencies and provides contextual help.

Results & Impact

The application has been successfully used by design teams to collaborate remotely on parametric design projects. It has significantly reduced the learning curve for non-technical team members to participate in the design process, leading to more diverse input and improved design outcomes.

The platform has also been adopted as an educational tool in several design schools, allowing students to explore parametric design concepts without the need for specialized software installations.
